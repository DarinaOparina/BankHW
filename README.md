## Модуль генераторов (generators.py)

В проекте реализованы три функции-генератора для эффективной поочередной обработки данных 
(транзакций и номеров карт) без загрузки всей информации в оперативную память.

### Описание функций

1. **`filter_by_currency(transactions, currency)`**
   * **Назначение:** Фильтрует список словарей с транзакциями, оставляя только те, у которых код валюты совпадает с заданным (например, `"USD"` или `"RUB"`).
   * **Особенность:** Использует безопасный метод `.get()` для извлечения данных из вложенных словарей, что предотвращает ошибки, если какого-то ключа не окажется в данных.

2. **`transaction_descriptions(transactions)`**
   * **Назначение:** Принимает список транзакций и поочередно возвращает текстовое описание (`description`) для каждой операции.

3. **`card_number_generator(start, end)`**
   * **Назначение:** Генерирует номера банковских карт в привычном формате `XXXX XXXX XXXX XXXX` для заданного диапазона чисел.
   * **Особенность реализации:** Функция написана с использованием базового синтаксиса (без использования сложных f-строк или метода `.zfill()`). Недостающие нули перед числом добавляются с помощью стандартного цикла `while` и проверки длины строки `len()`. Склеивание блоков происходит через обычное сложение строк (`+`).

## Тестирование (test_generators.py)

Для проверки корректности работы генераторов написаны тесты с использованием фреймворка `pytest`.

* **Использование фикстур:** Тестовые данные вынесены в специальную фикстуру `@pytest.fixture`, которая автоматически передается в нужные тесты. Никаких дополнительных импортов для работы фикстур не требуется — `pytest` связывает их автоматически по имени аргумента.
* **Покрытие тестами:** Проверены стандартные сценарии, случаи с пустыми списками транзакций, а также корректность маскирования и разбиения на блоки в генераторе карт.

### Запуск тестов

Для запуска тестов выполните в терминале команду:
```bash
pytest
```
## Модуль логирования (`src/decorators.py`)

Этот модуль предоставляет универсальный декоратор `@log`, который автоматически логирует результаты выполнения функций, параметры вызова, а также возникающие ошибки и исключения.

### Функционал
* Поддерживает необязательный аргумент `filename`.
* Если параметр `filename` передан — логи автоматически дописываются в указанный файл в кодировке `UTF-8`.
* Если параметр `filename` не передан — логи выводятся в стандартный поток вывода (`sys.stdout`/консоль).
* Логирует успешное выполнение функции в формате: `имя_функции ok`.
* При возникновении исключения логирует тип ошибки и переданные аргументы, после чего повторно генерирует (`raise`) ошибку, не нарушая работу приложения.

### Примеры использования

```python
from src.decorators import log

# 1. Логирование в консоль
@log()
def add(x, y):
    return x + y

# 2. Логирование в файл
@log(filename="app_logs.txt")
def divide(x, y):
    return x / y

add(2, 3)          # Выведет в консоль: add ok
divide(10, 0)      # Запишет в app_logs.txt ошибку ZeroDivisionError и пробросит её дальше
```
